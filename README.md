# TradeSphere Frontend

This package contains the **frontend-only static version** of the TradeSphere project.

## Included
- HTML pages for user and admin UI
- CSS styles
- Small JavaScript for frontend demo interactions
- Bootstrap / Bootstrap Icons / Chart.js loaded from CDN

## Removed
- Python / Flask backend
- MySQL database code and database files
- Virtual environment and Python packages
- Backend dependencies and cache files

## Important
This is a **static demo**. Login, registration, buy/sell, wallet and admin actions are visual only and do not save data because the Python backend and database were removed.

## Deploy
Upload the contents of this folder to any static hosting service such as GitHub Pages, Netlify, Vercel, or similar static hosting.

`index.html` is the homepage.
